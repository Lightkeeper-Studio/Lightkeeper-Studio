# Lightkeeper Studio

**Keeping a light on for hard days.**

Calm, private apps and books, made in the UK.

A lighthouse doesn't steer the ship. It just stays lit, so people can find their own way. That's what we try to build.

## What we promise

- **Private by default.** No accounts, no analytics, no ads, no tracking. Your records stay on your own device.
- **Works offline.** Each app is a single file that runs without a server.
- **Help is one tap away.** Every app that touches wellbeing shows where to get support, on every screen.
- **Realistic, not perfect.** A setback is information, not a verdict. Progress is never taken away.
- **Built for everyone.** Phone screens down to 320 pixels wide, large text, light and dark mode, and clear contrast.
- **Fair pricing.** The parts that keep people safe are always free. Extras are a one-off purchase, never a subscription.

## How we build

Plain HTML, CSS and JavaScript, with no framework and no build step. Every app has automatic checks for layout, text size, colour contrast and privacy, run on every change.
